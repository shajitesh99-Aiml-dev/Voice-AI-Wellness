I want to build a React + Tailwind CSS voice AI web app called "MindfulVoice" for drug awareness and mental wellness support.

Create a complete Replit project with the following:

## Tech Stack
- React 18
- Tailwind CSS
- Lucide React icons
- No backend needed (use localStorage for data persistence)

## Features Required

### 1. Voice Interface with Animated Orb
- A beautiful gradient orb (green to blue) that animates/pulses when recording
- Microphone button to start/stop voice recording
- Mock speech-to-text for demo (use random predefined phrases related to drug recovery)
- Orb shows recording state with pulsing rings

### 2. Chat/Conversation Interface
- Display conversation history (user messages on right with gradient background, AI on left as white cards)
- AI responses should be context-aware for drug recovery:
  - If user mentions "craving" → suggest grounding techniques
  - If user mentions "anxious" → offer breathing exercises
  - If user mentions "alone" → provide reassurance
  - If user mentions "trigger" → help identify patterns
  - If user mentions "proud" → celebrate progress and update streak
- Text input option as fallback
- Auto-save conversations to localStorage

### 3. Dashboard/Insights Page
- Show current streak count (days of positive engagement)
- Total conversations count
- Wellness score (calculated based on sentiment of messages)
- Common themes detected (cravings, anxiety, progress, etc.)
- Achievements/badges section
- AI-generated insight card with personalized recommendations

### 4. Crisis/Help Page
- Display emergency helpline numbers (mock numbers with call buttons)
- Grounding exercises (5-4-3-1, box breathing, urge surfing)
- Encouraging message
- Resources section

### 5. Bottom Navigation
- 3 tabs: Home (conversation), Insights (dashboard), Help (crisis)
- Apple-style bottom bar with icons
- Active tab highlighting

## Design Requirements
- Apple-style minimalist design
- Soft gradients (#f5f5f7 background)
- Glassmorphism effects (backdrop-blur)
- Rounded corners (24px cards, 40px buttons)
- Smooth animations and transitions
